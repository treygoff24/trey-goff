# Starter skill pack

<!-- DRAFT — pending real skill selection from the library and Trey's veto. -->

Six skills that pay for themselves in a week. Frontmatter and shape below;
paste any one into a session and say "create this skill for me."

## 1. review-my-diff

description: Review uncommitted changes for correctness and repo conventions.
Use when the user says "review this", "check my diff", or before a commit.

## 2. ship-a-release

description: Cut and publish a release. Use on "ship it" or "cut a release".

## 3. debug-loop

description: Reproduce, minimize, fix, prove. Use when something is broken
and the cause is unknown. Forbids speculative fixes without a repro.

## 4. write-human

description: Voice-first writing directive. Load BEFORE drafting prose.

## 5. session-closeout

description: End-of-session sweep. Update project notes, commit, write the
handoff. Use on "we are done" or "wrap up".

## 6. write-a-skill

description: Create or improve a skill. Use when a correction has now been
repeated twice and should become a procedure.
